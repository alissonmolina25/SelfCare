# SelfCare

SelfCare es una aplicación móvil enfocada en el autocuidado y el bienestar personal. Permite al usuario gestionar actividades relacionadas con su cuidado personal mediante una interfaz sencilla, agradable y organizada.

## Integrantes

- Vanessa Castaneda
- Andres Rivera
- Arnoldo Cardoza

## Tecnologías utilizadas

- Android Studio
- Java
- SQLite
- XML

## Características principales

- Registro de usuarios.
- Inicio de sesión.
- Almacenamiento local de información.
- Interfaz diseñada para dispositivos Android.
- Funcionamiento sin conexión a Internet.

## Proyecto académico

Proyecto desarrollado para el módulo **Desarrollo de Componentes para Dispositivos Móviles**.
